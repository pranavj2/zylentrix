## Introduction
- This project is created for "zylentrix" organizations assignment & Submission.
- In this project, api integration is done in order to fetch the list on UI.


## Features
  1. In this project, api call is done with "http" package.
  2. Clean architecture is used for the development.
  3. For state management bloc pattern is used.
  4. A separate posts_list_tile.dart file is created in order to show the list tile.
  5. For model class generation, json_serializable is used.
